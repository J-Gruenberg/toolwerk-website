# tool-werk.de

Statische Website von toolwerk (Marke der Grünberg Solutions GmbH). Alles, was live geht, liegt in `site/`.

- Hosting: Vercel-Projekt `toolwerk-website`, Domains tool-werk.de und angebote-in-minuten.de
- `vercel.json`: saubere URLs, `/aim` leitet auf `/`, Caching
- Design: toolwerk Design System (Claude Design), Startseite Version 6

Änderungen macht Claude in der Cloud: bauen, hier committen, auf Vercel deployen.
